How it works

The rules

1. Three colours are the digits. = 0, = 1, = 2. One cell holds one trit, a ternary digit, the three-state cousin of the bit. A trit carries log₂3 ≈ 1.58 bits, and base 3 is the closest whole number to e ≈ 2.718, the theoretically most economical base.

2. Short codes for frequent letters. A character is 1 to 4 colour cells long (up to 7 for Chinese). The most common letters get the shortest codes, as in Morse code and Huffman coding (the idea behind ZIP files and LLM tokenizers). E, T and A in English (О, Е, А in Russian) need a single cell.

3. White and black close every character. After its colour cells, each character ends with a marker: white = end of a letter, black = end of a word, so no space is needed. Because characters vary in length, this end signal is what keeps the reader in sync, just like the start and stop bits on a serial cable or the prefixes in UTF-8.

4. Empty cells carry no meaning. A marker that follows another marker (or opens the grid) is a filler and is skipped. That lets any text fill its frame exactly: the smallest square (side = √(cells), rounded up), landscape (about 3:2) or portrait (about 2:3) grid that holds the text and the key, with the spare white cells spread evenly between characters.

5. Four reading directions. A painting can be written left to right, right to left, top to bottom or bottom to top: row by row, or column by column, in any of the three formats. A text can also be written as a single line, read left to right: the same cells without the square and without the key, handy for signatures, borders and banners.

6. A direction key tells the reader which way, and which script. Every painting carries one key: 8 colour cells in a row. No character is longer than 7 cells, so this run can never appear inside text, and the key is always unique. The first 5 cells are fixed (); the last 3 name the script, which gives 3 × 3 × 3 = 27 script slots (10 in use, listed in the alphabet below). Its place is fixed by the Fibonacci sequence: in a grid of side n, the key starts at cell F(n) mod n², counted in reading order (6 × 6 → cell 8, 8 × 8 → cell 21, 9 × 9 → cell 34). A rectangle uses its longer side: in a W × H grid the key starts at F(longer side) mod W·H (9 × 6 → cell 34), which is the same rule for a square, so every square painting is unchanged. The reader tries all four directions and keeps the one where the key sits exactly at its Fibonacci cell. That also tells it the script, so nobody has to say which language a painting is in. Right-to-left scripts such as Hebrew and Arabic simply use the ← direction.

7. Any other character still fits. A special escape code is followed by the character's Unicode number in two 6-cell parts, so emoji and rare characters survive too.

8. Mondrian blocks: neighbours of one colour merge. In the blocks style, cells of the same colour that touch are drawn as one larger rectangle, without the black lines between them, so the painting looks like a real Mondrian. It is the idea of run-length encoding (RLE) in compression: a run of identical values is stored once, as one block. Each same-colour area is split into rectangles, largest first, so an L-shaped area becomes two blocks with a line between them. Only the picture changes: the cells underneath are the same, and the reader still samples the centre of every cell.

Where the ideas come from

Nothing here is new on its own. Each rule borrows one idea that already runs the digital world, which is what makes the code a good teaching tool.

How close to Huffman is it? Weighted by how often each letter appears in English, a letter takes 1.89 colour cells on average, instead of 3 in a fixed-length ternary code. Shannon's limit for a ternary code with no separators is about 2.63 cells per English letter. Mondrian Code goes below that on colour cells only because it adds a white or black marker to every character (2.89 cells in total). That is the deliberate trade-off: a true Huffman code is prefix-free, so it needs no separators, but it is hard to read by eye and one misread cell can scramble everything after it. Mondrian Code pays one marker per character for readability and recovery. Against a fixed 3-cell code plus marker (4 cells), text is about 28% shorter.

Compared with the bit system

Average cost of one English letter, weighted by letter frequency. A cell is one square, or one bit in a binary code. Efficiency = the information a letter really carries (Shannon: 4.17 bits) divided by what the code can hold in those cells.

What the numbers say. Mondrian Code needs the fewest squares of any code here that a person can read by eye: 2.89 per letter, against 4.20 bits for the best binary Huffman code (31% fewer) and 8 for ASCII (64% fewer). That is the advantage of three colours over two. But each square can show 5 states, and the white and black markers use part of that capacity, so in pure information terms it is about 62% efficient, where Huffman codes reach 97–99%. The markers are what you pay for being able to see where every letter ends and to recover after a misread cell. In real text the gap narrows: about one character in six is a space, which binary codes must store and Mondrian Code gets free inside the black marker.

The alphabet

Which languages it writes. Ten scripts, each with its own frequency table, cover most of the world's population:

  • Latin (ordered by English letter frequency): English, German, Swiss German, French, Italian, Spanish, Portuguese, Dutch, Danish, Norwegian, Swedish, Finnish, Romansh, and in Africa Swahili, Zulu, Xhosa, Somali, Afrikaans, Yoruba, Hausa, Igbo, Wolof and Lingala.
  • Cyrillic (ordered by Russian letter frequency): Russian, Ukrainian, Belarusian, Bulgarian, Serbian and Macedonian.
  • Chinese: the 3,249 most common Chinese characters (Mandarin, simplified).
  • Korean: Hangul, written as its letters (jamo) and rebuilt into syllable blocks when read.
  • Japanese: hiragana and katakana; kanji go through the escape code.
  • Arabic (with Persian letters), Hebrew, Greek, Hindi and other languages in Devanagari (Marathi, Nepali), and Ge'ez for Amharic and Tigrinya.

The other scripts

Open a script to see every character with its colours, and the three script cells it puts in the key. ◌ stands for the letter that a mark goes with (vowel signs, voicing marks). In Korean, ‑ㄱ is a final consonant.

What it is good for

Signature and art: a name, a date or a motto hidden in a logo, a poster or a print. Teaching: encode your own name and you have learned bits, bytes, variable-length codes, error checking and why an LLM turns words into tokens, in ten minutes. Puzzles: decode-the-poster challenges.

What it is not: encryption (anyone can break it by counting colours) or data storage (a QR code does that far better, with error correction).
